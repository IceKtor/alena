# Объектив — платформа для размещения и поиска портфолио фотографов

Учебный проект (КИТ СВФУ). Дизайн «Тёмная галерея» (макеты для Figma — в `design/`, 32 кадра: десктоп 1440 px и мобильная версия 390 px), требования — по ТЗ; серверная часть — **PHP 8.1+**, без фреймворков.

## Настройка MySQL и локальный запуск

Выберите пустую базу в phpMyAdmin, импортируйте `sql/schema.sql` и настройте соединение. [Инструкция по импорту и подключению](sql/README.md).

```bash
php -S localhost:8000 router.php
```

Открыть http://localhost:8000. Для хостинга нужен PHP 8.1+ с PDO MySQL и GD.

**Демо-вход** (после необязательного импорта `sql/demo.sql`): `foto@demo.ru` (фотограф, доступен личный кабинет) или `client@demo.ru` (заказчик, работает «избранное»), пароль `demo12345`.

## Структура

| Путь | Что это |
|---|---|
| `index.php`, `photographers.php`, `photographer.php`, `works.php`, `about.php`, `cabinet.php`, `privacy.php`, `404.php` | страницы по ТЗ (+ `favorites.php`) |
| `partials/` | шапка, подвал, модальные окна, иконки, карточки |
| `css/style.css`, `js/app.js` | стили (цвета и размеры — переменные в `:root`, те же, что в макете) и интерфейс |
| `design/` | макеты в SVG для Figma, исходники дизайн-системы |
| `server/` | настройки, данные, валидация, авторизация; `server/api/*.php` — обработчики форм |
| `img/photos/` | заглушки вместо фото (из макета) |
| `sql/` | схема MySQL и необязательные демонстрационные данные |

Для сборки статической демо-копии через `tools/export_static.py` используйте отдельную базу с импортированным `sql/demo.sql`.
