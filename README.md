# Объектив — платформа для размещения и поиска портфолио фотографов

Учебный проект (КИТ СВФУ). Вёрстка выполнена по макету Figma (дизайн-система «Поларoид») и ТЗ; серверная часть — **PHP 8**, без фреймворков.

## Запуск локально

```bash
php -S localhost:8000 router.php
```

Открыть http://localhost:8000. На обычном хостинге (Apache) достаточно положить файлы в корень сайта — `.htaccess` уже есть.

**Демо-вход** (пока нет базы): `foto@demo.ru` (фотограф, доступен личный кабинет) или `client@demo.ru` (заказчик, работает «избранное»), пароль `demo12345`.

## Структура

| Путь | Что это |
|---|---|
| `index.php`, `photographers.php`, `photographer.php`, `works.php`, `about.php`, `cabinet.php`, `privacy.php`, `404.php` | страницы по ТЗ (+ `favorites.php`) |
| `partials/` | шапка, подвал, модальные окна, иконки, карточки |
| `css/style.css`, `js/app.js` | стили (цвета — переменные в `:root`) и интерфейс |
| `server/` | настройки, данные, валидация, авторизация; `server/api/*.php` — обработчики форм |
| `img/photos/` | заглушки вместо фото (из макета) |
| `uploads/` | будущие загрузки (выполнение скриптов запрещено) |
| `sql/` | сюда лягут схема и тестовые данные БД |

## Заглушки под базу данных (MySQL / phpMyAdmin)

Сейчас данные — тестовые, из `server/data.php`. Все места, которые потом нужно переписать на SQL, помечены `TODO(DB)`:

```bash
grep -rn "TODO(DB)" server partials *.php
```

Порядок подключения БД описан в `sql/README.md`. Валидация, роли, CSRF и защита от перебора пароля уже работают на сервере.
