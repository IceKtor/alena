# База данных (будет позже)

Сайт пока работает на тестовых данных из `server/data.php`. Когда понадобится БД (MySQL/MariaDB, phpMyAdmin):

1. Создать базу `obyektiv` (utf8mb4) и импортировать схему сюда, в `sql/` (например `schema.sql`, `seed.sql`).
2. Заполнить `DB_*` в `server/config.php` и поставить `DB_ENABLED = true`.
3. Переписать функции в `server/data.php` на запросы через `db()` (`server/db.php`).
   Каждое место помечено `TODO(DB)`; формат возвращаемых массивов менять не нужно.

Сущности (ТЗ, раздел 8.2): пользователь, профиль фотографа, жанр (справочник, связь «многие ко многим»),
работа, услуга, свободная дата, заявка, избранное, просмотр профиля, отзыв, сообщение обратной связи.

Найти все заглушки: `grep -rn "TODO(DB)" server partials *.php`
