# MySQL и phpMyAdmin

1. В phpMyAdmin создайте пустую базу со сравнением `utf8mb4_unicode_ci`. Выберите её и через вкладку **Импорт** загрузите `schema.sql` в UTF-8. Файл создаёт таблицы и добавляет справочники городов и жанров.
2. Для учебного просмотра можно сразу после схемы импортировать `demo.sql`. Он добавляет прежний каталог и два учебных аккаунта. Для публичного сайта с реальными пользователями импортируйте только схему.
3. Задайте переменные окружения `DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USER`, `DB_PASS` или создайте `server/config.local.php` по примеру ниже. Файл игнорируется Git. Имя базы и параметры пользователя берутся из панели хостинга, порт MySQL обычно 3306.

```php
<?php
const DB_HOST = 'localhost';
const DB_PORT = 3306;
const DB_NAME = 'obyektiv';
const DB_USER = 'ваш_пользователь';
const DB_PASS = 'ваш_пароль';
```

4. Включите в PHP 8.1 или новее модули `pdo_mysql`, `mbstring`, `fileinfo` и `gd` с поддержкой JPG/PNG. Для загрузки работ по 10 МБ задайте `upload_max_filesize = 10M`, `post_max_size = 12M`, `memory_limit = 256M` и MySQL `max_allowed_packet` не менее 32 МБ. Изображения и миниатюры сохраняются в базе вместе с работами. В резервную копию базы входят и фотографии.
5. Запустите сайт командой `php -S localhost:8000 router.php` из корня проекта или откройте его через Apache с обработкой `.htaccess`.

Для проверки зарегистрируйте фотографа, заполните профиль и загрузите работу. В другом браузере или после выхода отправьте ему заявку. Она появится в разделе «Заявки» даже после повторного входа. Заказчик может добавить профиль в избранное.

Учебные аккаунты из `demo.sql` — `foto@demo.ru` и `client@demo.ru`, пароль обоих `demo12345`. Сообщения формы «Написать нам» доступны в таблице `feedback_messages`.
