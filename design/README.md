## Как открыть в Figma
1. Установите (или убедитесь, что есть в Figma) шрифты: **Cormorant Garamond**, **Inter**, **IBM Plex Mono** (все бесплатные, есть в Google Fonts).
2. Перетащите SVG-файлы на холст Figma. Тексты остаются текстом, фото встроены.
3. Если файл импортировался группой, выделите её и нажмите Ctrl+Alt+G («Frame selection»), чтобы получить фрейм.

Auto layout при импорте из SVG не сохраняется: это обычные слои. Фото сейчас заглушки из первого макета.

## Исходники
В `source/`: `design.css` — все стили (десктоп и мобильная версия в одном файле), `build.py` — сборка экранов, `render.js` — выгрузка в SVG. Эти же стили станут основой при переносе дизайна на сайт.
